# Binary Arcade

Browser games for KS3 Computing about how computers store images and sound in binary.

## Pixels
- **Pixel Decoder**: paint a picture from rows of binary (1-bit and 2-bit colour).
- **Pixel Encoder**: write the binary for each row of a picture.
- **Colour Studio**: draw with 1, 2 or 3 bits per pixel and see the binary and file size.
- **Image File Size**: practice questions on width × height × colour depth.

## Sound
- **Beep Decoder**: high beep = 1, low beep = 0. Decode numbers, ASCII letters and words.
- **Beep Maker**: type a message and hear it as binary beeps.
- **Sampling Lab**: change sample rate and bit depth, see and hear the result.
- **Sound File Size**: practice questions on sample rate × bit depth × seconds.

## Running it
It's a single file with no build step. Open `index.html` in a browser.
