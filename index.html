Pixel Decoder

Each row of binary is one row of the picture. Paint the pixels to match the code, then check. Drag to paint lots at once.

Key words

Pixel
One tiny square of colour. Short for “picture element”.
Bitmap
An image stored as a grid of pixels. Each pixel is saved as a binary code.
1-bit image
Each pixel uses 1 bit, so it can only be one of 2 colours. Here 1 = black, 0 = white.
Colour depth
The number of bits used for each pixel. 2 bits gives 4 colours: 00, 01, 10, 11.

Pixel Encoder

1 black 0 white

Now go the other way. Type the binary for each row of the picture. Black is 1 and white is 0. Each row needs 8 bits.

How to encode

Work left to right
Read each row like a sentence. Write 1 for every black pixel and 0 for every white one.
Count your bits
The picture is 8 pixels wide, so every row has exactly 8 bits.
Why it matters
A computer can only store 1s and 0s. This is how a picture becomes data it can save and send.

More bits, more colours

2 colours (0, 1)
2 bits
4 colours (00, 01, 10, 11)
3 bits
8 colours (000 to 111)
24 bits
Over 16 million colours. This is what most photos use.
colours = 2colour depth

Each extra bit doubles the colours, but it also makes every pixel bigger, so the whole file gets bigger.

Image File Size

Work out how much storage a bitmap image needs.

The formula

size in bits =
width × height × colour depth
Resolution
How many pixels the image has, written as width × height.
Bits to bytes
8 bits make 1 byte, so divide the number of bits by 8.
Example
An 8 × 8 image with a 2-bit colour depth needs 8 × 8 × 2 = 128 bits, which is 16 bytes.

Beep Decoder

A high beep is 1 and a low beep is 0. Listen, tap the bits to match what you hear, then convert the binary.

Letter codes (ASCII)

Sound as binary

Two sounds, two digits
Old modems and fax machines sent data down phone lines as tones. One pitch meant 1 and another meant 0.
Place values
Add up the place values above every 1. For 1011 that is 8 + 2 + 1 = 11.
ASCII
A code that gives every character a number. Capital A is 65, which is 01000001.

Key words

Sample
One measurement of the sound wave’s height, stored as a binary number.
Sample rate
How many samples are taken each second, measured in hertz (Hz). More samples follow the wave more closely.
Bit depth
How many bits store each sample. More bits give more levels, so each measurement is more accurate.
size in bits =
sample rate × bit depth × seconds

Sound File Size

Work out how much storage a sound recording needs.

The formula

size in bits =
sample rate × bit depth × seconds
Example
10 seconds at 100 Hz with a 4-bit depth: 100 × 4 × 10 = 4,000 bits.
Bits to bytes
Divide by 8. So 4,000 bits is 500 bytes.
Watch out
Change minutes into seconds first. 1 minute = 60 seconds.
